# 14th-fe-assignment-6

영남대 멋쟁이사자처럼 14기 프론트엔드 트랙 6차시 과제

1. 기본 라우팅 구현
- `/`
  - 로그인 전: 로그인 안내 문구 및 로그인 이동 버튼 출력
  - 로그인 후: 환영 문구 및 서비스 이용 버튼 출력

- `/login`
  - 아이디/비밀번호 입력창 및 로그인 버튼 구현
  - Navbar가 보이지 않는 단독 페이지 구성

- `/mypage`
  - 로그인한 사용자의 프로필 정보 출력
  - 비로그인 상태에서는 로그인 필요 문구 출력

- `*`
  - 잘못된 주소 접근 시 404 페이지 출력
  - 이전 페이지 이동 기능 구현

2. 레이아웃 & 중첩 라우팅
- Layout 컴포넌트 내부에 Navbar와 Outlet 배치
- 중첩 라우팅을 사용하여 Home과 MyPage가 Outlet 위치에서 렌더링되도록 구현
 Navbar 상태 변화
- 로그인 전: [홈]
- 로그인 후: [홈], [마이페이지], [로그아웃]

3. Router Hook 활용
- useNavigate를 사용하여 로그인 후 홈(`/`)으로 자동 이동 구현
- `replace: true` 옵션을 사용하여 뒤로가기 시 로그인 페이지가 다시 나타나지 않도록 설정
- 404 페이지에서 `navigate(-1)`을 사용한 뒤로가기 기능 구현
